A standalone diagnostic script implementing all 4 diagnostics from D-07. Structure:

```python
#!/usr/bin/env python
"""Phase 7 D-06/D-07: RTFM XD-I3D reproduction gap diagnostics.

Investigates the 65.70% vs 77.81% AP gap between our reproduction and
the published RTFM result. Goal: diagnose and document, not close the gap.

Diagnostics:
  1. Annotation alignment -- compare Wu parser output vs published protocol
  2. Temporal interpolation -- verify snippet->frame expansion matches RTFM
  3. I3D feature audit -- compare feature statistics vs published dimensions
  4. Published code comparison -- document training regime differences

Usage:
    python scripts/rtfm_gap_diagnostic.py

Output: results/phase7_rtfm_gap_diagnostic.json
"""
```

Each diagnostic is a function returning a dict with `status`, `finding`, and `detail` keys:

- `diagnostic_annotation_alignment()`: Load our xd_temporal.txt via `parse_xd_annotations()`, verify 800 test videos parsed, check that normal test videos (label_A) have no annotation entries, check interval format. Compare against expected: Wu annotations file has one row per abnormal video with frame intervals.

- `diagnostic_temporal_interpolation()`: Read our snippet_to_frame.py logic, verify it uses `np.repeat(scores, snippet_window)` with snippet_window=16 for I3D path. Compare to published RTFM code which uses `np.repeat(pred, 16)`. Report: MATCH or MISMATCH.

- `diagnostic_i3d_feature_audit()`: Load one I3D feature file from E:/i3d-features/i3d-features/RGB/ (if available), report shape and statistics (mean, std, min, max). Compare to published RTFM expected: 2048-d 10-crop vs our 1024-d 5-crop. Report dimensional mismatch.

- `diagnostic_published_code_comparison()`: Build a comparison table documenting the known training regime differences from RESEARCH.md:
  - lr: 1e-4 (ours) vs 1e-3 (RTFM)
  - margin: 1.0 (ours, sigmoid [0,1]) vs 100 (RTFM, feature magnitudes)
  - batch_size: 3 (ours, 5-crop x3=15 effective) vs 32 (RTFM)
  - features: 1024-d 5-crop (ours) vs 2048-d 10-crop (RTFM)
  - schedule: cosine warmup 50 epochs (ours) vs constant lr 15k iterations (RTFM)
  - optimizer: AdamW wd=1e-2 (ours) vs Adam (RTFM)
  - early stopping: patience=10 (ours) vs none (RTFM)
  - k_topk: 3 (both -- same)

The main() function runs all 4 diagnostics, prints a summary table to stdout, and writes the full results to `results/phase7_rtfm_gap_diagnostic.json`. The conclusion section states: "The 12.11pp AP gap is overwhelmingly a training regime difference (10x lower LR, 2x smaller features, different loss scaling), not an evaluation bug."
