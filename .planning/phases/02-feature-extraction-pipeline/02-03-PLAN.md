  <action>
    Create `scripts/verify_alignment.py` that runs in the `vcc-main` conda environment. This script checks that every video in the split files has matching skeleton and CLIP feature files with identical snippet counts.

    **Command-line interface:**
    ```
    python scripts/verify_alignment.py --dataset ucf|xd [--split train|val|test|all] [--sample N] [--verbose]
    ```
    - `--dataset`: which dataset to verify
    - `--split`: which split to verify (default: "all" = train+val+test)
    - `--sample N`: verify only N randomly sampled videos (for quick checks during extraction)
    - `--verbose`: print per-video details

    **Verification checks per video:**

    1. **File existence:**
       - `E:\features\{dataset}\skeleton\{video_id}.npy` exists
       - `E:\features\{dataset}\clip\{video_id}.npy` exists
       - `E:\snippets\{dataset}\{video_id}_boundaries.json` exists

    2. **Shape validation:**
       - Load skeleton .npy with `np.load(path, mmap_mode='r')` (memory-efficient)
       - Assert shape is `(N, 256)` where N > 0
       - Assert dtype is float32
       - Load clip .npy with `np.load(path, mmap_mode='r')`
       - Assert shape is `(N, 1024)` where N > 0
       - Assert dtype is float32

    3. **Snippet count alignment (DATA-08, the core check):**
       - `n_skel = skel_features.shape[0]`
       - `n_clip = clip_features.shape[0]`
       - Assert `n_skel == n_clip`
       - Load boundary JSON, assert `n_skel == boundary['n_snippets']`

    4. **Quality checks (spot-check, not exhaustive):**
       - No NaN values: `assert not np.any(np.isnan(features))`
       - No Inf values: `assert not np.any(np.isinf(features))`
       - Non-zero variance: `assert features.var() > 1e-10` (catches collapsed features, C1 warning sign)

    5. **Report format:**
       ```
       === Alignment Verification: UCF-Crime ===
       Split: all (train + val + test)
       Total videos checked: 1560
       PASS: 1556
       FAIL: 4
       SKIP (missing files): 0

       Failures:
         - Fighting042: n_skel=5, n_clip=4 (MISMATCH)
         ...

       Summary statistics:
         Snippet count range: 1 - 47
         Mean snippets per video: 12.3
         Skeleton feature norm range: [0.12, 4.56]
         CLIP feature norm range: [0.89, 1.23]
       ```

    6. **Exit code:** Return 0 if all videos pass. Return 1 if any failures. This allows CI-style gating.

    7. **Coverage check:** Compare video IDs in split files against video IDs with feature files. Report any videos in splits that have no features (indicates extraction was incomplete).
  </action>
