    2. **Per-video processing loop:**
       a. Read video IDs from `data/splits/{dataset}_{split}.txt`.
       b. For each video_id:
          - **Skip-if-exists (D-14):** Check if `E:\features\{dataset}\skeleton\{video_id}.npy` exists. If yes, skip.
          - Load pickle from `E:\skeletons\{dataset}\{video_id}.pkl`.

    3. **Preprocessing pipeline per snippet (CRITICAL — must match PYSKL contract):**
       For each snippet defined by `snippet_frame_ranges`:
       a. Slice keypoints: `kp_snippet = keypoint[:, start:end, :, :]`  shape `[2, 64, 17, 2]`
       b. Slice scores: `sc_snippet = keypoint_score[:, start:end, :]`  shape `[2, 64, 17]`

       c. **Apply PreNormalize2D (DATA-04, C1 pitfall):**
          ```python
          h, w = pickle_data['img_shape']
          kp_snippet[..., 0] = (kp_snippet[..., 0] - (w / 2)) / (w / 2)
          kp_snippet[..., 1] = (kp_snippet[..., 1] - (h / 2)) / (h / 2)
          ```
          Assert `np.all(np.abs(kp_snippet[..., :2]) <= 2.0)`.

       d. **Generate 4 stream inputs using PYSKL transforms:**
          - **Joint (j):** `x_j = np.concatenate([kp_snippet, sc_snippet[..., None]], axis=-1)` shape `[2, 64, 17, 3]` (x, y, conf)
          - **Bone (b):** Compute bone vectors using COCO_BONE_PAIRS:
            ```python
            bone = np.zeros_like(kp_snippet)  # [2, 64, 17, 2]
            for v1, v2 in enumerate(COCO_BONE_PAIRS):
                bone[:, :, v1, :] = kp_snippet[:, :, v1, :] - kp_snippet[:, :, v2[1], :]
            bone_score = sc_snippet.copy()  # use same scores
            x_b = np.concatenate([bone, bone_score[..., None]], axis=-1)  # [2, 64, 17, 3]
            ```
            NOTE: COCO_BONE_PAIRS[i] = (child, parent). Bone vector = child - parent. For joint 0, pair is (0,0) so bone is zero vector.
          - **Joint Motion (jm):** Temporal difference of joint:
            ```python
            jm = np.zeros_like(kp_snippet)  # [2, 64, 17, 2]
            jm[:, 1:, :, :] = kp_snippet[:, 1:, :, :] - kp_snippet[:, :-1, :, :]
            jm_score = sc_snippet.copy()
            x_jm = np.concatenate([jm, jm_score[..., None]], axis=-1)  # [2, 64, 17, 3]
            ```
          - **Bone Motion (bm):** Temporal difference of bone:
            ```python
            bm = np.zeros_like(bone)  # [2, 64, 17, 2]
            bm[:, 1:, :, :] = bone[:, 1:, :, :] - bone[:, :-1, :, :]
            bm_score = sc_snippet.copy()
            x_bm = np.concatenate([bm, bm_score[..., None]], axis=-1)  # [2, 64, 17, 3]
            ```

       e. **Forward pass through each stream:**
          ```python
          def extract_stream_feature(model, x_np, device='cuda'):
              # x_np: [2, 64, 17, 3] -> add batch dim -> [1, 2, 64, 17, 3]
              x = torch.from_numpy(x_np).unsqueeze(0).float().to(device)
              with torch.no_grad():
                  out = model.backbone(x)  # [1, M, 256, T', V']
                  feat = out.mean(dim=[1, 3, 4])  # [1, 256]
              return feat.cpu()
          ```

       f. **Weighted average (per D-01, DATA-05):**
          ```python
          feat = (1.0 * feat_j + 1.0 * feat_b + 0.5 * feat_jm + 0.5 * feat_bm) / 3.0
          # Result: [1, 256] float32
          ```

    4. **CLIP feature extraction per snippet:**
       ```python
       def extract_clip_snippet(frames, preprocess, model, batch_size=64):
           """frames: list of PIL Images. Returns [1024] float32 numpy array."""
           if len(frames) == 0:
               return np.zeros(1024, dtype=np.float32)  # edge case: no frames sampled

           tensors = torch.stack([preprocess(f) for f in frames])  # [N, 3, 224, 224]
           all_feats = []
           for i in range(0, len(tensors), batch_size):
               batch = tensors[i:i+batch_size].cuda()
               with torch.no_grad():
                   feats = model.encode_image(batch)  # [B, 512]
                   feats = feats / feats.norm(dim=-1, keepdim=True)  # L2 normalize
               all_feats.append(feats.cpu().float())
           embeddings = torch.cat(all_feats, dim=0)  # [N_frames_in_snippet, 512]

           mean_feat = embeddings.mean(dim=0)        # [512]
           max_feat = embeddings.max(dim=0).values    # [512]
           concat = torch.cat([mean_feat, max_feat], dim=0)  # [1024]
           return concat.numpy().astype(np.float32)
       ```

    5. **IMPORTANT — 1024-d output, NOT 512-d (Pitfall 5 from research):**
       The cache stores 1024-d features (mean+max concatenation). The learned projection to 512-d happens in Phase 3's CLIP branch, NOT during extraction. This avoids the double-projection pitfall.
