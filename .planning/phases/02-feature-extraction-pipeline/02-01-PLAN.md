  <action>
    Create `scripts/extract_skeletons.py` that runs in the `vcc-skeleton` conda environment. This script takes raw video frames (UCF-Crime PNGs or XD-Violence mp4 files) and produces two outputs per video: (1) a PYSKL-compatible pickle file with skeleton keypoints, and (2) a snippet boundary JSON file.

    **Command-line interface:**
    ```
    python scripts/extract_skeletons.py --dataset ucf|xd --split train|val|test [--limit N] [--workers 1]
    ```
    - `--dataset`: which dataset to process
    - `--split`: which split to process (reads video IDs from data/splits/{ucf|xd}_{split}.txt)
    - `--limit N`: process only the first N videos (for testing)
    - `--workers`: number of parallel workers (default 1, skeleton extraction is GPU-bound)

    **Core extraction logic:**

    1. **Frame loading:**
       - UCF-Crime (per D-04): Load PNGs from `E:\UCF_crime_dataset\{Train|test}\{category}\{video_id}_x264_{framenum}.png`. Group by video_id (prefix before `_x264_`). Sort frame indices NUMERICALLY (not lexicographically — Pitfall from research). Determine category by checking which category directory contains the video's PNGs.
       - XD-Violence: Decode frames using `decord.VideoReader(str(video_path), ctx=decord.cpu(0))`. Load ALL frames for skeleton extraction. Fall back to `cv2.VideoCapture` if decord raises an exception.

    2. **RTMPose inference (per D-05, D-06, D-07, D-08):**
       ```python
       from rtmlib import Wholebody
       # Initialize once:
       wholebody = Wholebody(
           pose='rtmpose-m',  # RTMPose-medium COCO-17
           mode='lightweight',
           backend='onnxruntime',
           device='cuda'
       )
       ```
       - For each frame, call `wholebody(frame)` which returns `(keypoints, scores)`.
       - `keypoints` shape: `[N_persons, 133, 2]` (wholebody has 133 keypoints). Take only first 17 (COCO-17 body keypoints): `keypoints[:, :17, :]`.
       - `scores` shape: `[N_persons, 133]`. Take `scores[:, :17]`.
       - **Top-2 person selection (D-05):** If N_persons > 2, select the 2 persons with highest mean keypoint confidence: `mean_conf = scores[:, :17].mean(axis=1)`, then `top2_idx = np.argsort(mean_conf)[-2:]`.
       - **No minimum threshold (D-06):** Accept all detections regardless of confidence.
       - **Zero-pad missing persons (D-07, D-08):**
         - 0 detections: both person slots are all-zero keypoints and all-zero scores.
         - 1 detection: person 0 = detected, person 1 = all-zero.
         - 2+ detections: take top-2 by mean confidence.
       - Process frames in chunks of 500 to avoid RAM overflow (Pitfall 9 from research).

    3. **Build per-video arrays:**
       - `keypoint`: ndarray shape `[M=2, T, V=17, C=2]` where T = total frames, C = (x_pixel, y_pixel)
       - `keypoint_score`: ndarray shape `[M=2, T, V=17]` — per-joint confidence
       - Read actual frame resolution from the first frame: `img_shape = (H, W)` from `cv2.imread(first_frame_path).shape[:2]` for UCF-Crime or from the first decoded frame for XD-Violence. Do NOT hardcode resolution (Pitfall 3 from research).

    4. **Compute snippet boundaries (per D-01 — critical for alignment, Pattern 2 from research):**
       ```python
       def compute_snippet_boundaries(n_frames, frames_per_snippet=64):
           boundaries = []
           for start in range(0, n_frames - frames_per_snippet + 1, frames_per_snippet):
               boundaries.append([start, start + frames_per_snippet])
           return boundaries
       # Discard trailing frames that don't fill a complete 64-frame window
       ```
       - Write snippet boundary JSON to `E:\snippets\{dataset}\{video_id}_boundaries.json`:
         ```json
         {
             "video_id": "Fighting002",
             "total_frames": 269,
             "frames_per_snippet": 64,
             "snippet_frame_ranges": [[0, 64], [64, 128], [128, 192], [192, 256]],
             "n_snippets": 4,
             "img_shape": [720, 1280]
         }
         ```

    5. **Write PYSKL-compatible pickle (per DATA-03):**
       - Output path: `E:\skeletons\{dataset}\{video_id}.pkl`
       - Pickle dict format:
         ```python
         {
             'keypoint': keypoint,           # [M=2, T, V=17, C=2] float32
             'keypoint_score': keypoint_score, # [M=2, T, V=17] float32
             'img_shape': (H, W),            # actual frame resolution
             'total_frames': T,
             'video_id': video_id
         }
         ```

    6. **Resume logic (per D-14):** Before processing each video, check if `E:\skeletons\{dataset}\{video_id}.pkl` AND `E:\snippets\{dataset}\{video_id}_boundaries.json` both exist. If both exist, skip. Log skipped count.

    7. **Error handling (per D-15):** Wrap per-video processing in try/except. On failure, log `{video_id}\t{error_message}` to `E:\skeletons\{dataset}\errors.log` and continue. The 4 known CRC-corrupt XD-Violence files are expected failures.

    8. **Progress bar (per D-16):** Use `tqdm` with total=len(video_ids), showing video_id in the description.

    9. **Coordinate normalization assertion (per DATA-04, C1 pitfall):**
       After building the keypoint array for each video, apply PreNormalize2D:
       ```python
       def prenormalize2d(keypoint, img_shape):
           h, w = img_shape
           kp = keypoint.copy().astype(np.float32)
           kp[..., 0] = (kp[..., 0] - (w / 2)) / (w / 2)
           kp[..., 1] = (kp[..., 1] - (h / 2)) / (h / 2)
           return kp
       ```
       Assert `np.all(np.abs(normalized_kp[..., :2]) <= 2.0)` — use 2.0 tolerance because joints at image edges can slightly exceed 1.0. Log a WARNING (not error) if any video fails this assertion, and include the max absolute value in the warning.
