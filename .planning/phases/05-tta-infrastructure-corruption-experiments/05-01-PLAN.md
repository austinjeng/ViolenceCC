**4 corruption functions** (all share the same signature):
```python
def gaussian_noise(img: np.ndarray, severity: int, rng: np.random.Generator) -> np.ndarray:
```
- Convert uint8 to float32 [0,1], add `rng.normal(0, sigma, img.shape)`, clip to [0,255], return uint8.
- `sigma = GAUSSIAN_NOISE_SIGMA[severity - 1]`

```python
def jpeg_compression(img: np.ndarray, severity: int, rng: np.random.Generator = None) -> np.ndarray:
```
- Use `cv2.imencode('.jpg', bgr, [cv2.IMWRITE_JPEG_QUALITY, quality])` + `cv2.imdecode(buf, cv2.IMREAD_COLOR)`.
- Convert RGB->BGR before encode, BGR->RGB after decode. `quality = JPEG_QUALITY[severity - 1]`.
- `rng` unused but present for uniform signature.

```python
def brightness(img: np.ndarray, severity: int, rng: np.random.Generator = None) -> np.ndarray:
```
- Convert to float32 [0,1], add `BRIGHTNESS_FACTOR[severity - 1]`, clip to [0,255], return uint8.
- Per Claude's discretion: use ImageNet-C convention (add only, not subtract) for comparability.

```python
def motion_blur(img: np.ndarray, severity: int, rng: np.random.Generator = None) -> np.ndarray:
```
- Create horizontal line kernel: `kernel = np.zeros((size, size), float32)`, `kernel[size//2, :] = 1.0/size`.
- Apply via `cv2.filter2D(img, -1, kernel)`.
- `size, _ = MOTION_BLUR_PARAMS[severity - 1]` (second element unused for simplified horizontal kernel per Assumption A1).
