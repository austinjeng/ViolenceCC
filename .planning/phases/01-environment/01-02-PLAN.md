Create all three conda environments sequentially. Each environment has specific Python version and package requirements that MUST NOT be mixed.

**CRITICAL:** The base conda is Python 3.12.4. Every `conda create` command MUST explicitly specify `python=3.11` or `python=3.10` to avoid inheriting the wrong Python version (Pitfall P5 from RESEARCH.md).

**Environment 1: vcc-skeleton (Python 3.11)**
```bash
conda create -n vcc-skeleton python=3.11 -y
conda run -n vcc-skeleton pip install rtmlib==0.0.15
conda run -n vcc-skeleton pip install onnxruntime-gpu
conda run -n vcc-skeleton pip install opencv-python opencv-contrib-python numpy tqdm
```

Smoke test:
```bash
conda run -n vcc-skeleton python -c "import rtmlib; print('rtmlib OK')"
conda run -n vcc-skeleton python -c "import onnxruntime; print('ORT:', onnxruntime.__version__); print('CUDA:', 'CUDAExecutionProvider' in onnxruntime.get_available_providers())"
```

**Environment 2: vcc-ctrgcn (Python 3.10)**

First, ensure PYSKL is cloned:
```bash
ls D:/libs/pyskl/setup.py 2>/dev/null || git clone https://github.com/kennymckormick/pyskl.git D:/libs/pyskl
```

Then create environment:
```bash
conda create -n vcc-ctrgcn python=3.10 -y
conda install -n vcc-ctrgcn pytorch==1.12.1 torchvision==0.13.1 cudatoolkit=11.3 -c pytorch -c conda-forge -y
conda run -n vcc-ctrgcn pip install mmcv-full==1.7.0 -f https://download.openmmlab.com/mmcv/dist/cu113/torch1.12.0/index.html
conda run -n vcc-ctrgcn pip install mmdet==2.25.1 mmpose==0.29.0
conda run -n vcc-ctrgcn pip install -e D:/libs/pyskl --no-deps
conda run -n vcc-ctrgcn pip install decord numpy scipy tqdm pytest
```

**WARNING:** The mmcv-full wheel URL uses `torch1.12.0` in the path, not `torch1.12.1`. This is correct -- OpenMMLab indexes by minor version (Pitfall P1 from RESEARCH.md).

If `decord` fails on Windows, install the fork:
```bash
conda run -n vcc-ctrgcn pip install eva-decord
```

Smoke test:
```bash
conda run -n vcc-ctrgcn python -c "import torch; print('PyTorch:', torch.__version__); print('CUDA:', torch.cuda.is_available())"
conda run -n vcc-ctrgcn python -c "import mmcv; print('mmcv:', mmcv.__version__)"
conda run -n vcc-ctrgcn python -c "import pyskl; print('PYSKL OK')"
```

**Environment 3: vcc-main (Python 3.11)**
```bash
conda create -n vcc-main python=3.11 -y
conda run -n vcc-main pip install torch==2.6.0 torchvision==0.21.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124
conda run -n vcc-main pip install open-clip-torch==3.3.0 timm
conda run -n vcc-main pip install scikit-learn h5py numpy scipy tqdm PyYAML wandb tensorboard
conda run -n vcc-main pip install kornia Pillow
conda run -n vcc-main pip install decord
```

If `decord` fails:

Each `conda create` command will take 1-3 minutes. The pip installs for vcc-main (PyTorch 2.6 cu124 wheels) will take longer (~5-10 min) due to the ~2GB download.

  <action>
Extract datasets and create the feature directory junction. These are long-running operations (69.5 GB + 39 GB extraction) that should run sequentially to avoid I/O contention on E: drive.

**CRITICAL -- Pitfall P3:** Use the `-o` flag with 7-Zip to set the output directory directly. Do NOT let 7-Zip create per-zip subdirectories. All training videos must end up flat in `E:\XD_Violence\train\`, not in `E:\XD_Violence\train\1-1004\`.

1. **Create target directories:**
```bash
mkdir -p E:/XD_Violence/train E:/XD_Violence/test E:/i3d-features E:/features
```

2. **Extract XD-Violence training zips (5 archives, ~69.5 GB total):**
```bash
"/c/Program Files/7-Zip/7z.exe" x E:/1-1004.zip -oE:/XD_Violence/train/ -y
"/c/Program Files/7-Zip/7z.exe" x E:/1005-2004.zip -oE:/XD_Violence/train/ -y
"/c/Program Files/7-Zip/7z.exe" x E:/2005-2804.zip -oE:/XD_Violence/train/ -y
"/c/Program Files/7-Zip/7z.exe" x E:/2805-3319.zip -oE:/XD_Violence/train/ -y
"/c/Program Files/7-Zip/7z.exe" x E:/3320-3954.zip -oE:/XD_Violence/train/ -y
```

3. **Extract XD-Violence test zip:**
```bash
"/c/Program Files/7-Zip/7z.exe" x E:/XD_violence_test_video.zip -oE:/XD_Violence/test/ -y
```

4. **Extract I3D features (for RTFM baseline in Phase 4, per D-13):**
```bash
"/c/Program Files/7-Zip/7z.exe" x E:/i3d-features.zip -oE:/i3d-features/ -y
```

5. **Create NTFS junction for feature directory (per D-06):**
```bash
# Use Windows cmd for junction creation (mklink is a cmd built-in, not bash)
cmd.exe /c "mklink /J D:\ViolenceCC\data\features E:\features"
```

6. **Verify junction works:**
```bash
ls D:/ViolenceCC/data/features/
```
Should list E:\features\ contents (empty initially, which is correct).

7. **Verify XD-Violence extraction:**
```bash
ls E:/XD_Violence/train/ | head -10
ls E:/XD_Violence/train/ | wc -l
ls E:/XD_Violence/test/ | head -10
ls E:/XD_Violence/test/ | wc -l
```
Training should have video files (MP4) directly in the directory, NOT in subdirectories named after the zip archives.

**Timing note:** The 7-Zip extraction of ~110 GB total will take approximately 15-30 minutes depending on E: drive speed. Each zip extraction can be run sequentially.
