## EVAL-01 (RTFM XD-I3D) Gate — BLOCKED by Architectural Gap

**Status:** HALTED — Rule 4 architectural deviation surfaced

**AP:** not measured (training failed at loader-construction time)
**Gate:** >= 0.7681 — **CANNOT EVALUATE**

### What happened

1. **Preflight** (`scripts/wandb_preflight.py`) exited 2 — no `WANDB_API_KEY` and no `~/.netrc`.
2. **Rule 3 fallback applied** (plan Step A Option C): set `wandb.mode: disabled` in `configs/rtfm_i3d.yaml` + passed `--no-preflight` to `run_ablations.py`.
3. **Training subprocess failed with `KeyError: 'skeleton_features'`** in `src/data/loaders.py:104`.

### Architectural root cause

Plan 04-03's SUMMARY claims D-36 was implemented: "`train.py + evaluate.py dispatch via cfg['dataset'] == 'xd_i3d' → I3DFeatureDataset`".

**Empirical finding:** This dispatch does NOT exist in code.

- `src/train.py` — no `xd_i3d` branch; the train loop unconditionally consumes `nor_batch["skel"]`, `nor_batch["clip"]`, `nor_batch["mask"]` (MIL skel+clip contract from Phase 3).
- `src/data/loaders.py:102-113` — `build_dataloaders()` unconditionally constructs `MILFeatureDataset(skel_dir=paths["skeleton_features"], clip_dir=paths["clip_features"], ...)`. Since `configs/rtfm_i3d.yaml` intentionally omits `skeleton_features` / `clip_features` (per D-36), this raises `KeyError`.
- `src/data/i3d_dataset.I3DFeatureDataset` IS implemented, but is not wired into the training path. Only `src/eval/test_loader.py:103-112` imports it.
- `src/evaluate.py:172-174` — the xd_i3d label-construction branch is a documented stub ("Plan 04-03 will wire the xd_i3d label construction from the Wu et al. annotations"). All labels defaulted to zero.

### Why this is Rule 4, not Rule 1/2/3

The fix requires significant structural changes to the training pipeline:

1. Add a `build_dataloaders_i3d()` (or equivalent dispatch) that constructs `I3DFeatureDataset` with a single `feature_dir` parameter. D-19 requires 5-crop expansion in train (5× effective bags) and 5-crop averaging in test, which is incompatible with `MILFeatureDataset`'s paired skel+clip structure.
2. Add a new `train_one_epoch_i3d(...)` that consumes `[B, T, 1024]` i3d tensors (or `[B*5, T, 1024]` 5-crop expanded) rather than paired skel+clip+mask.
3. Add a new `validate_i3d(...)` matching the above signature.
4. Adjust `mil_ranking_loss` call — the MIL contract and `n_normal` split still apply, but inputs are i3d-only.
5. Wire the xd_i3d label construction in `src/evaluate.py:_build_frame_arrays` using the actual Wu et al. XD-Violence annotations (not all-zero stubs), otherwise every `AUC` / `AP` value is meaningless.

This is **not** a missing column or a simple null check — it is a whole second training code path parallel to the fusion MIL pipeline, plus a ground-truth annotation wiring step.

### Proposed paths forward (researcher decision required)

**Option A: Insert a pre-Task-2 implementation plan (recommended).** Insert a new plan `04-06a` before the empirical queue to fully implement D-36 in train.py + build_dataloaders + evaluate.py's xd_i3d label construction. Estimated 1-2 days of TDD. Only after 04-06a completes does the RTFM gate become runnable.

**Option B: Drop the RTFM gate entirely and execute only the UCF-only phase 4 main ablations.** Per D-01 the full Phase 4 scope is UCF-only; the RTFM gate was retargeted to XD-I3D per D-03, but if the xd_i3d training path is incomplete, we can treat EVAL-01 as deferred-to-Phase-4b and run Tasks 3-5 (UCF main + pooling + 3-seed) immediately. Risk: the RTFM gate catches silent C4-expansion bugs and architecture-impl bugs; losing it increases the chance of shipping a broken UCF pipeline undetected.

**Option C: Rescope EVAL-01 to UCF (the PRD's original gate).** Revert D-03 back to the PRD-original gate ("RTFM baseline reproduction on UCF-Crime — target 84.30% AUC within +/-1%"). This would let the existing MILFeatureDataset-based pipeline serve the gate run. Trade-off: no RTFM XD-I3D reproduction, but Phase 4b can still re-establish it after XD skel+CLIP features finish.

**Recommendation:** Option A.
