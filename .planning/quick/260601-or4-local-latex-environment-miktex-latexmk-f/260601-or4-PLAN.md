  <name>Task 1: Install MiKTeX (user-scope) + latexmk and enable on-the-fly package auto-install</name>
  <files>(no repo files; installs MiKTeX to $env:LOCALAPPDATA\Programs\MiKTeX)</files>
  <action>
Install the MiKTeX TeX distribution at user scope via winget, then ensure latexmk and automatic package installation are configured.

Steps (run in a foreground/visible PowerShell terminal per the no-headless convention):
1. Install MiKTeX user-scope, non-interactively:
   winget install -e --id MiKTeX.MiKTeX --scope user --accept-package-agreements --accept-source-agreements
   If winget reports MiKTeX is already installed, treat as success and continue.
2. Resolve the MiKTeX bin directory. Expected user-scope path: $env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64. Verify it exists with Test-Path. If it does not exist there, search under $env:LOCALAPPDATA\Programs and $env:USERPROFILE for miktex\bin\x64 and use the found path. Capture this as $miktexBin for use by full-path invocation (do NOT depend on PATH being refreshed in this session).
3. Enable on-the-fly auto-install of missing packages (so acmart's CTAN dependencies download during the first compile without prompts):
   & "$miktexBin\initexmf.exe" --set-config-value "[MPM]AutoInstall=1"
   (initexmf is the MiKTeX config tool. The MPM AutoInstall=1 value makes the package manager install missing packages automatically rather than prompting.)
4. Ensure latexmk is present. MiKTeX usually ships latexmk; confirm with Test-Path "$miktexBin\latexmk.exe". If missing, install it via the MiKTeX package manager: & "$miktexBin\mpm.exe" --install=latexmk  (mpm = MiKTeX Package Manager CLI).

IMPORTANT — sandbox/elevation fallback: if winget cannot run in the executor's shell (sandbox refusal, elevation prompt, or interactive license gate), DO NOT hang or retry blindly. Surface to the user the exact commands above (winget install line + the initexmf AutoInstall line) for them to run in a visible terminal, then continue once they confirm the bin dir exists.
  </action>
