# Quick Task 260604-w2a: Fix TTA dropout-in-train-mode bug (deterministic TTA scores)

## Goal

`configure_model` (src/tta/tent.py) calls `model.train()` (needed so LN affine params
get gradients) then disables ONLY the top-level `GatedFusion.dropout`. The two
`nn.Dropout(0.3)` layers inside `MILHead.mlp` (`head.mlp.2`, `head.mlp.5`) stay in
**train mode**, so every TTA forward (source_only, TENT, SAR) is stochastic. Measured
on the trained CLIP checkpoint: per-condition AUC std ~1.07pp, and the Table-3-level
20-condition mean wobbles ~0.24pp run-to-run — larger than the reported TTA deltas.

Fix: disable ALL `nn.Dropout` modules in `configure_model`, and add a `manual_seed` in
the eval entry for reproducibility. This makes TTA scores deterministic (LayerNorm is
mode-invariant; with dropout off the forward is exact). **Code-only fix. No paper edit,
no re-run, no canonical-artifact change in this task** — the corrected grid re-run and
any paper update happen separately, after review.

## Tasks

### Task 1 — `src/tta/tent.py`: disable all dropout in `configure_model`

Replace (lines ~50-52):
```
    # Pitfall 6: disable dropout during TTA
    if hasattr(model, "dropout"):
        model.dropout.eval()
```
with:
```
    # Pitfall 6: disable ALL dropout during TTA. model.train() (needed for LN
    # gradient flow) turns every dropout on; disabling only the top-level
    # GatedFusion.dropout left MILHead's two nn.Dropout layers (head.mlp.2,
    # head.mlp.5) in train mode, making every TTA score stochastic. Loop over
    # all modules so no dropout is missed.
    for m in model.modules():
        if isinstance(m, nn.Dropout):
            m.eval()
```
Also update the module-docstring bullet (line ~10) "4. Dropout explicitly set to eval
after model.train() (Pitfall 6)" → "4. ALL Dropout modules set to eval after
model.train() (Pitfall 6)".

- `files`: src/tta/tent.py
- `verify`: `grep -n "isinstance(m, nn.Dropout)" src/tta/tent.py` matches inside configure_model; the old `hasattr(model, "dropout")` line is gone. `python -c "import torch,torch.nn as nn,sys; sys.path.insert(0,'.'); from src.models.gated_fusion import GatedFusion; from src.tta.tent import configure_model; m=GatedFusion(clip_dim=1024); configure_model(m); print('train-mode dropouts:', [n for n,mm in m.named_modules() if isinstance(mm,nn.Dropout) and mm.training])"` prints an EMPTY list.
- `done`: configure_model disables every nn.Dropout; existing tests still import.
