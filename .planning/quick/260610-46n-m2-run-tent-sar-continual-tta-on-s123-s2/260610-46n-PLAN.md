# Quick Task 260610-46n: Fix M2 — make TENT/SAR a true 3-seed result

## Problem (audit M2, MEDIUM, adversarially verified)

`paper/main.tex:325` states "All TTA results are means over three training seeds
{42,123,2024}", but TENT/SAR had only ever been run on the **seed-42** source
checkpoint (`results/_tta_rerun_continual/<bb>/{source,tent,sar}/`). Source-Only and
Ours (disc_reweight) were genuinely 3-seed; the blanket "all three seeds" was false
for TENT/SAR. The entropy negative result (`<0.1pp`) was therefore single-seed.

## Approach

The corrupted UCF-Crime-C feature caches are **seed-independent** (corruption is
applied to frames before backbone extraction), and all 12 gated-fusion source
checkpoints (s42/s123/s2024 × 4 backbones) already exist on disk — so the fix needs
only TENT/SAR **adaptation+scoring** on the s123/s2024 checkpoints, no re-extraction.

1. `scripts/run_tta_seeds_m2.py` drives the **identical committed** continual
   protocol (`src.tta.evaluate_tta.run_tta_evaluation`, `protocol="continual"`,
   TENT lr=1e-3, SAR lr=1e-3 ρ=0.05) over s123+s2024 × 4 backbones × {source,tent,sar}
   × 20 conditions = 480 condition-runs (resumable; skips existing).
   - verify: each condition writes `eval_metrics.json` with an AUC.
2. Aggregate the 3-seed mean entropy delta (tent−source, sar−source) per backbone.
   - verify: worst |Δ| < 0.1pp so the paper's "<0.1pp on every backbone" holds.
3. Persist `results/_tta_rerun_continual/summary_3seed.json` and point
   `scripts/aggregate_tta_table.py` at it (3-seed) with seed-42 fallback.
   - verify: `aggregate_tta_table.py` still reproduces Table 3 exactly.
4. Paper: NO edit needed — `:325`/`:327` become literally true once 3-seed data exists.

## Result

477 ran (3 probes pre-existing), 42 min. 3-seed mean ΔTENT/ΔSAR: CLIP +0.021/+0.024,
Base −0.082/−0.077, SO400M −0.050/−0.051, Giant +0.011/+0.012. **Worst |Δ| = 0.082pp
< 0.1pp → claim HOLDS.** Table 3 unchanged. Bonus: 3-seed continual source mean
(63.71/57.01/58.87/62.83) now matches Table-3 Source-Only (63.7/57.0/58.9/62.8).

## Scope

Compute + provenance artifact + regenerator update. No paper edit, no numeric change
to any table. Per-condition files stay gitignored (regenerable via the driver), matching
the seed-42 convention; only `summary_3seed.json` is committed (force-added).
