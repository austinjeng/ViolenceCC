# Quick Task 260610-4pk: Knock out the 4 LOW audit items (code/doc hygiene)

From the 2026-06-09 full audit. All LOW, no headline/paper impact; I3D/RTFM path is a
non-paper baseline. Adversarially verified findings.

## Tasks

1. `src/data/i3d_dataset.py` (`#`-comment split lines): the id comprehension only filtered
   blanks, so the 2 `# Excluded:` lines in xd_train.txt inflated the startup "available"
   count by 2. Mirror `dataset.py:148` — add `and not i.strip().startswith("#")`.
   - verify: comment lines never enter `all_ids`.
2. `src/data/i3d_dataset.py` (`_resample_T` fixed seed): `np.random.default_rng(0)` produced
   identical sub-T indices every epoch and across all 5 crops. Switch to the global RNG
   (`np.random.randint`, like `MILFeatureDataset`) so sampling varies per epoch/crop, still
   reproducible via the train-time global seed.
   - verify: tests pass; sampling no longer constant.
   - note: the 2 committed rtfm_i3d baseline rows (non-paper) were produced with the old
     sampling and are NOT re-run.
3. `src/models/rtfm_i3d.py:5` docstring: claimed "FM head = L2 norm of features" but the
   forward is LayerNorm + standard sigmoid MILHead. Reword to reflect the code.
4. `src/evaluate.py` XD comments: the "bit-identical to gt.npy (2,330,384 frames)" comment is
   true only for the xd_i3d stride-16 path. Scope it, and document at the xd FUSION site that
   `n_frames=len(scores)*64` truncates ~0.74% trailing frames (2,313,024), AP-negligible.
