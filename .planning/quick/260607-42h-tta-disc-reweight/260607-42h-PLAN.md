GatedFusion forward attributes (src/models/gated_fusion.py:48-62) — the disc_reweight
forwards operate on these by name:
  skel_proj: Linear(skel_dim, shared_dim)
  ln_skel:   LayerNorm(shared_dim)
  clip_proj: Linear(clip_dim, shared_dim)
  ln_clip:   LayerNorm(shared_dim)
  gate:      Linear(2*shared_dim, shared_dim)
  ln_fused:  LayerNorm(shared_dim)
  head:      MILHead -> scores

Canonical GatedFusion forward (reference, scripts/_tmp_tta_harness.py:ref_forward):
  p_skel = ln_skel(skel_proj(skel))
  p_clip = ln_clip(clip_proj(clip))
  g      = sigmoid(gate(cat([p_skel, p_clip], -1)))
  out    = ln_fused(g*p_skel + (1-g)*p_clip + p_skel + p_clip)
  return head(out).squeeze(-1)
