# Phase quick-260607-42h Plan 01: disc_reweight TTA method Summary

Production-ified the validated R1 "discriminative-reliability routing" TTA method as a new `--method disc_reweight` choice in the canonical `evaluate_tta.py` entry point: a label-free, tuning-free per-condition scalar `w` that scales the VL (clip) stream after `ln_clip` (in both the fused term and the residual highway of GatedFusion), routing toward the corruption-robust skeleton stream exactly where the VL stream collapses.

## What Was Built

- **`src/tta/disc_reweight.py`** — new pure helper library (no `scripts/_tmp_*` imports, device-agnostic):
  - `accumulate(items, load)` — streaming float64 mean/cov (`cov = ss/n - outer(mu,mu)`), ported from `_tmp_coral_derisk.py:_accumulate`.
  - `mean_shift_z` / `mean_abs_z` — per-channel mean-shift z (`z = (mu_t-mu_s)/sd_s`, `sd_s = sqrt(clip(diag(C_s),1e-12,None))`), ported from `_tmp_tta_harness.py:shift_stats` + `_tmp_r1_full.py:meanZ`.
  - `clip_only_forward(model, skel, clip)` — canonical GatedFusion forward with the skeleton zeroed (`p_skel = ln_skel(zeros_like(skel_proj(skel)))`).
  - `w_scaled_forward(w)` — returns a forward fn that scales `p_clip` by `w` AFTER `ln_clip` (documented: scaling the clip INPUT is nulled by `ln_clip`).
  - `clip_only_std(model, skels, clips, vids, T=32)` — std over pooled clip-only snippet scores.
  - `compute_w(clip_std_test, clip_std_clean, skelZ, skelZ_floor)` — pure scalar routing math, returns `(w, w_vl, skel_rel)`.
- **`src/tta/evaluate_tta.py`** — argparse choice `disc_reweight`; import of the ported helpers; a `_run_disc_reweight(...)` two-pass dispatch (plus `_load_condition_videos` / `_load_clean_split` loaders) inserted BEFORE the existing adaptor construction, so `source_only` / `tent` / `sar` call paths are untouched. Pass 1 derives `clip_std_test` + `skelZ` over the loaded condition and computes `w`; pass 2 scores every video with `w_scaled_forward(w)` using the existing chunked T=32 / frame-expansion / `compute_frame_metrics` convention. Clean refs (`clip_std_clean`, `skelZ_floor`) and clean-train skeleton stats are computed once. Output JSON carries the standard metric keys plus routing diagnostics (`disc_w`, `disc_w_vl`, `disc_skel_rel`, `clip_std_test`, `clip_std_clean`, `skelZ`, `skelZ_floor`); `lr`/`rho`/`protocol` are ignored (label-free, tuning-free, transductive — noted in a comment).
- **`tests/test_disc_reweight.py`** — 5-case `compute_w` unit test (no disk/GPU), `--method disc_reweight` parse test, and a `source_only`-unchanged regression on a self-contained synthetic fixture.
