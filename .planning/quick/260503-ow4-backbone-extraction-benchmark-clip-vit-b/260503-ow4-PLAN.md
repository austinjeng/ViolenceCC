<objective>
Create a cross-environment backbone feature extraction benchmark that measures the REAL
computational cost of each feature extractor (CLIP ViT-B/16, RTMPose-m + YOLOX, CTR-GCN
4-stream, I3D RGB) and produces a unified comparison table for thesis inclusion.

Purpose: The existing benchmark_models.py only measures the lightweight MIL heads (sub-ms).
The actual extraction backbones are orders of magnitude more expensive and run in separate
conda environments. This script bridges all three envs via JSON intermediaries.

Output: scripts/benchmark_backbones.py + per-component JSON results + combined table output
</objective>

  <name>Task 1: Create cross-environment backbone benchmark script</name>

  <action>
Create `scripts/benchmark_backbones.py` with the following architecture:

**CLI interface:**
- `--clip` : benchmark CLIP ViT-B/16 (must run in vcc-main)
- `--rtmpose` : benchmark RTMPose-m + YOLOX (must run in vcc-skeleton)
- `--ctrgcn` : benchmark CTR-GCN 4-stream (must run in vcc-ctrgcn)
- `--combine` : read all JSON results, add I3D published row, produce unified tables
- `--all` : shell out to all 3 envs via direct python exe paths, then combine
- `--num-warmup` (default 10) and `--num-bench` (default 50) for timing control
- `--batch-size` (default 64, used by CLIP and CTR-GCN; RTMPose is always single-frame)

**Component: CLIP ViT-B/16** (`_bench_clip`):
- Load model: `open_clip.create_model_and_transforms("ViT-B-16", pretrained="openai")`
- Input: `torch.randn(B, 3, 224, 224)` dummy tensors
- Parameters: `sum(p.numel() for p in model.visual.parameters())` — use `model.visual` not full model (we only benchmark the visual encoder, not text)
- FLOPs: use thop with a `_ThopWrapper` that calls `model.encode_image(x)`. Use batch=1 for FLOPs.
- Latency: `time.perf_counter()` with `torch.cuda.synchronize()`, warmup then bench loops
- Memory: `torch.cuda.reset_peak_memory_stats()` + `max_memory_allocated()`
- Per-frame cost: `latency_ms / batch_size`
- Write results to `results/backbone_bench_clip.json`

**Component: RTMPose-m** (`_bench_rtmpose`):
- cuDNN PATH fix at top: `C:\Program Files\NVIDIA\CUDNN\v9.8\bin\12.8`
- Load model: `rtmlib.Body(mode="balanced", backend="onnxruntime", device="cuda")`
- Input: `np.random.randint(0, 255, (480, 640, 3), dtype=np.uint8)` — single frame
- Parameters: PUBLISHED ("~13M total: YOLOX ~9M + RTMPose-m ~4M") — cannot count from ONNX easily
- FLOPs: PUBLISHED ("~3.2 GFLOPs total: YOLOX ~1.0 + RTMPose-m 2.22")
- Latency: `time.perf_counter()` per-frame, no batch dimension. Warmup 5 frames, then bench N frames. Compute mean, P50, P95.
- Memory: Use `onnxruntime` session — cannot use `torch.cuda.max_memory_allocated`. Instead, query GPU memory before and after with `torch.cuda.mem_get_info()` if torch is available, or just report "N/A (ONNX Runtime)". Prefer: import pynvml or subprocess nvidia-smi query. Simplest approach: `import subprocess; result = subprocess.run(["nvidia-smi", "--query-gpu=memory.used", "--format=csv,noheader,nounits"], capture_output=True, text=True)` before and after model load + inference. Report the delta.
- Per-frame cost: direct (already per-frame measurement)
- Write results to `results/backbone_bench_rtmpose.json`

**Component: CTR-GCN 4-stream** (`_bench_ctrgcn`):
- Load all 4 streams using the same pattern as `extract_ctrgcn.py:load_ctrgcn_stream()`:
  - Config: `D:/libs/pyskl/configs/ctrgcn/ctrgcn_pyskl_ntu120_xsub_hrnet/{j,b,jm,bm}.py`
  - Weights: `D:/ViolenceCC/data/weights/ctrgcn/{j,b,jm,bm}.pth`
  - `mmcv.Config.fromfile()` + `pyskl.models.build_model()` + `load_state_dict(strict=False)`
- Input per stream: `torch.randn(1, 2, 64, 17, 2)` — shape [N=1, M=2, T=64, V=17, C=2]
- Forward per stream: `model.backbone(x)` then pool over M/T/V dims to get [N, 256]
  - Actually, mimic the extraction script: the model forward includes backbone + pooling.
  - Use `model.extract_feat(x)` if available, else `model.backbone(x)` + manual pool.
  - Safest: just call `model.backbone(x)` which returns [N*M, C_out, T', V'] then reshape/pool as done in extract_ctrgcn.py.
- Parameters: count per-stream (`sum(p.numel() ...)`) and report per-stream AND total (4-stream sum)
- FLOPs: try thop per stream with batch=1. If thop fails (mmcv custom ops), fall back to manual estimate or report "N/A".
- Latency: time full 4-stream pass (all 4 sequential, as in extraction). Also report per-stream.
- Memory: `torch.cuda.reset_peak_memory_stats()` + `max_memory_allocated()` (PyTorch 1.12 supports this)
- Per-snippet cost: latency for one 4-stream pass (= 1 snippet of 64 frames)
- Write results to `results/backbone_bench_ctrgcn.json`

**Component: I3D RGB** (hardcoded in combine):
- Source: Carreira & Zisserman, "Quo Vadis, Action Recognition?" (2017)
- Parameters: 25.0M (published)
- FLOPs: 107.9 GFLOPs per clip (published)
- Latency/Throughput/Memory: "Pre-extracted (not measured)" — these features are downloaded, not computed by this project
- Mark all published values with a `"source": "published"` key in the result dict

**Combine mode** (`_combine_results`):
- Read `results/backbone_bench_{clip,rtmpose,ctrgcn}.json` — skip missing with warning
- Add I3D hardcoded row
- Produce 3 outputs:

  1. **Console table** (follow benchmark_models.py pattern):
     ```
     Backbone         | Params (M) | FLOPs (G) | Latency    | Throughput  | GPU Mem (MB) | Per-Frame
     CLIP ViT-B/16    |     86.2   |    17.6   | 45.3 ms/B  |   1412 f/s  |      1820    | 0.71 ms
     RTMPose-m+YOLOX  |    ~13*    |   ~3.2*   | 46.1 ms/f  |   21.7 f/s  |       N/A    | 46.1 ms
     CTR-GCN (4-str)  |     6.4    |    XX.X   | 12.3 ms/sn |   81.3 sn/s |       890    | -- (snippet)
     I3D RGB          |    25.0*   |  107.9*   | Pre-extracted          |       ---    | ---
     ```
     Mark published values with * asterisk.

  2. **Pipeline Cost Summary** — total extraction time per video snippet:
     - Skeleton path: RTMPose (per_frame_ms * 64 frames) + CTR-GCN (per_snippet_ms) = total ms/snippet
     - CLIP path: CLIP (per_frame_ms * sampled_frames, assume ~6 frames/snippet at 1 FPS for 64-frame snippet at ~10 FPS) = total ms/snippet
     - I3D path: "Pre-extracted features; published cost: 107.9 GFLOPs/clip"

  3. **LaTeX booktabs table** (thesis-ready, `\begin{table}` wrapper with caption and label)

  4. **CSV** to `results/backbone_bench_combined.csv`

**Style/conventions:**
- Follow `benchmark_models.py` patterns: argparse, `_isnan` helper, `time.perf_counter()` + `torch.cuda.synchronize()`
- Project root detection: `_PROJECT_ROOT = str(Path(__file__).resolve().parent.parent)`
- `sys.path.insert(0, _PROJECT_ROOT)` at top
- `os.makedirs` before JSON/CSV writes
- Reproducibility header at start (PyTorch version, CUDA version, GPU name, config)
- Each component function is self-contained (imports inside function for env isolation)
- Use `if __name__ == "__main__": main()` pattern

**Important: do NOT import rtmlib, mmcv, pyskl, or open_clip at module level.**
Each component function imports its own dependencies inside the function body.
This allows the same script file to be invoked in any env — only the selected
component's imports run.
