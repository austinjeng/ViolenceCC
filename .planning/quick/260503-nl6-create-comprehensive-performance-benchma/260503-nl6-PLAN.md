patch thop or use custom_ops; the wrapper approach is standard practice.

<task type="auto">
  <name>Task 2: Create benchmark_models.py</name>
  <files>scripts/benchmark_models.py</files>
  <action>
Create `scripts/benchmark_models.py` -- a self-contained script that benchmarks all 5
ViolenceCC model variants. Run in `vcc-main` env via `conda run -n vcc-main python scripts/benchmark_models.py`.

**Structure:**

1. **Constants at top:**
   - BATCH_SIZE = 16, T = 32, SKEL_DIM = 256, CLIP_DIM = 1024, I3D_DIM = 1024
   - NUM_WARMUP = 50 (GPU warmup iterations before timing)
   - NUM_BENCH = 200 (timed iterations for latency/throughput)
   - DEVICE = "cuda" (assert torch.cuda.is_available())

2. **Model config table** -- dict mapping variant name to:
   - `build_kwargs`: kwargs for build_model() (use defaults from registry)
   - `input_factory`: function returning the dict of dummy tensors for forward()
   - `thop_args_factory`: function returning positional tuple for thop.profile()
   
   Concrete input factories:
   - skeleton_only: `dict(skel=torch.randn(B,T,256).cuda())`
   - clip_only: `dict(clip=torch.randn(B,T,1024).cuda())`
   - late_fusion: `dict(skel=torch.randn(B,T,256).cuda(), clip=torch.randn(B,T,1024).cuda())`
   - gated_fusion: `dict(skel=torch.randn(B,T,256).cuda(), clip=torch.randn(B,T,1024).cuda())`
   - rtfm_i3d: `dict(i3d=torch.randn(B,T,1024).cuda())`

3. **Wrapper class for thop** -- thin nn.Module wrapper per variant that accepts positional
   args and delegates to the real model with keyword args. Example:
   ```python
   class _ThopWrapper(nn.Module):
       def __init__(self, model, input_keys):
           super().__init__()
           self.model = model
       def forward(self, *args):
           kwargs = dict(zip(self.input_keys, args))
           return self.model(**kwargs)
   ```

4. **benchmark_one(variant_name, model, inputs, thop_wrapper, thop_inputs)** function:
   
   a. **Parameters**: `sum(p.numel() for p in model.parameters())` for total,
      `sum(p.numel() for p in model.parameters() if p.requires_grad)` for trainable.
      Report in raw count and in "K" (thousands) since these are small MIL heads.
   
   b. **FLOPs/MACs**: Use `thop.profile(thop_wrapper, inputs=thop_inputs, verbose=False)`.
      thop returns (macs, params). Report MACs and FLOPs (= 2 * MACs) in millions (M).
      Wrap in try/except -- if thop fails for a variant, fall back to manual calculation
      and print a warning.
   
   c. **Peak GPU memory**:
      - `torch.cuda.reset_peak_memory_stats()`
      - `torch.cuda.synchronize()`
      - Run one forward pass
      - `torch.cuda.synchronize()`
      - `peak_mb = torch.cuda.max_memory_allocated() / 1024**2`
   
   d. **Latency** (ms/batch and ms/sample):
      - model.eval(), torch.no_grad()
      - Warmup: NUM_WARMUP forward passes (discard)
      - torch.cuda.synchronize()
      - time NUM_BENCH forward passes using time.perf_counter with
        torch.cuda.synchronize() before start and after end
      - latency_ms = total_time / NUM_BENCH * 1000
      - per_sample_ms = latency_ms / BATCH_SIZE
   
   e. **Throughput**: samples/sec = BATCH_SIZE / (latency_ms / 1000)
   
   Return a dict with all metrics.

5. **Main loop**: iterate over all 5 variants in order:
   [skeleton_only, clip_only, late_fusion, gated_fusion, rtfm_i3d]
   
   For each: build model via build_model(), move to CUDA, set eval mode,
   call benchmark_one(), collect results.

6. **Output formatting**:
   
   a. **Console table** using string formatting (no external dependency like tabulate).
      Columns: Model | Params (K) | MACs (M) | FLOPs (M) | Latency (ms/batch) | Latency (ms/sample) | Throughput (samples/s) | Peak GPU (MB)
      Use f-string alignment for clean columns. Print separator lines.
   
   b. **LaTeX table** string printed to console (copy-paste ready for thesis).
      Standard booktabs format:
      ```
      \begin{table}[t]
      \centering
      \caption{Model complexity comparison.}
      \label{tab:model-complexity}
      \begin{tabular}{lrrrrr}
      \toprule
      Model & Params (K) & MACs (M) & Latency (ms) & Throughput (s/s) & Mem (MB) \\
      \midrule
      ... rows ...
      \bottomrule
      \end{tabular}
      \end{table}
      ```
   
   c. **CSV output** saved to `results/benchmark_models.csv` (create results/ dir if needed).
      Use csv.writer. Same columns as console table.

7. **Display names** for thesis readability:
   - skeleton_only -> "Skeleton-Only"
   - clip_only -> "CLIP-Only"  
   - late_fusion -> "Late Fusion"
   - gated_fusion -> "Gated Fusion"
   - rtfm_i3d -> "RTFM-I3D"

8. Add `if __name__ == "__main__":` guard. Add argparse with optional flags:
   - `--batch-size` (default 16)
   - `--num-warmup` (default 50)
   - `--num-bench` (default 200)
   - `--cpu` flag to run on CPU (skip GPU memory measurement)
   - `--no-latex` flag to suppress LaTeX output
   - `--no-csv` flag to suppress CSV output

**Important implementation details:**
- Import `sys` and insert project root: `sys.path.insert(0, str(Path(__file__).resolve().parent.parent))`
  so `from src.models.registry import build_model` works.
- All models must be in eval() mode with torch.no_grad() for benchmarking.
- Delete model and run `torch.cuda.empty_cache()` between variants to avoid memory bleed.
- Print GPU name at the top: `torch.cuda.get_device_name(0)`.
- Print PyTorch version and CUDA version for reproducibility header.
